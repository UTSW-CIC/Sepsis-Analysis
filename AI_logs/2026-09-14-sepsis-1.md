# Sepsis 1 categorization

## Approved decisions

- Sepsis 1 is suspected infection plus qualifying SIRS evidence.
- Use the configured infection-to-SIRS window, currently 24 hours backward
  and 24 hours forward from each infection anchor.
- Treat every distinct suspected-infection evidence row as an independent
  anchor. Deduplicate only exact matches on encounter, timestamp, criterion,
  and infection type.
- If `sirs_episode_filter_config.enabled` is true, classification uses only
  SIRS-positive episodes retained by the existing episode filter. Do not
  rebuild the filtering logic.
- Add `effective_sirs_positive_flag` and pass the enabled state explicitly,
  matching the filtered-hypotension integration pattern.
- For each qualifying infection/SIRS association, `sepsis_1_dt` is the later
  of the infection anchor and SIRS episode start: the point when both pieces
  of evidence have been established. Retain the earlier timestamp separately
  as `sepsis_1_earliest_evidence_dt`.
- SIRS episodes and association windows use half-open interval overlap. Exact
  boundary contact with no elapsed overlap does not qualify.

## Implementation

- Added `src_strategy/events/sirs/effective_state.py` to map existing raw and
  filtered SIRS episode lineage to classification-effective positive flags.
- Added `src_strategy/events/sepsis/sepsis1.py` with:
  - exact infection-anchor deduplication and stable per-encounter anchor IDs;
  - evidence-preserving infection/SIRS associations;
  - one-row-per-encounter Sepsis 1 classification and evidence counts.
- Added Sepsis 1 column names and association-window validation to
  `src_strategy/configs/severitysepsis.py`.
- Integrated suspected infection, SIRS episode reconstruction/filtering,
  effective SIRS state, Sepsis 1 associations, and encounter summaries into
  `main_strategy.py` using versioned, no-overwrite outputs.
- Removed the stale downstream block that loaded `df_sirs.parquet` and saved
  separate unversioned SIRS filter artifacts.
- Added `tests/test_sepsis1.py`.

## Validation

- Focused Sepsis 1 tests: 9 passed.
- Focused Sepsis 1 plus SIRS regression tests: 18 passed before the additional
  onset-direction test; the new focused suite then passed 9/9.
- Full suite: 192 passed and 2 failed. Both failures reflect owner-approved
  current configuration/behavior rather than new Sepsis 1 regressions:
  - an old test expects the SIRS episode filter to be disabled by default,
    while configuration currently enables it;
  - an old suspected-infection test expects only the earliest antibiotic/
    culture pair, while the owner intentionally retained every evidence row.
- Read-only smoke test on existing artifacts, with the SIRS filter enabled:
  - 814,102 suspected-infection evidence rows;
  - 309,240 exact-deduplicated infection anchors;
  - 661,966 raw SIRS episodes and 207,079 filtered positive episodes;
  - 280,479 effective positive raw SIRS episodes;
  - 1,245,109 qualifying evidence associations;
  - 13,579 Sepsis 1-positive encounters among 14,914 encounters.
  No patient-level rows were printed or written.

## Review notes and next gates

- The independent-anchor policy is intentionally sensitivity-first. Paired
  evidence can produce many overlapping windows; the inline code comment
  recommends comparing this later with canonical infection-episode grouping.
- Before implementing Sepsis 2, re-open the pulmonary definition and obtain
  owner confirmation because the current pulmonary implementation does not yet
  represent all four support/P/F tiers in the authoritative document.
- At Sepsis 2 categorization, remind the owner of the prior vasopressor
  decision: medication orders remain evidence but do not qualify shock; only a
  recorded positive administration dose qualifies.
