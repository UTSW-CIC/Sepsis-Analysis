# Sepsis 2 categorization

## Confirmed starting definition

- Sepsis 2 is suspected infection plus at least one organ dysfunction.
- Sepsis 1/SIRS is not a prerequisite.
- Preserve evidence and timestamps for later POA/NPOA classification.
- Prior shock decision reminder: medication orders remain audit evidence but
  do not qualify shock; only a recorded positive vasopressor administration
  dose qualifies. This will matter when Sepsis 2 composes into Sepsis 3.

## Blocking clinical-alignment question — awaiting owner answer

Question: Should pulmonary dysfunction first be corrected to the complete
four-tier definition in `docs/clinical_definitions 3_1.docx` before Sepsis 2
composition, or should Sepsis 2 intentionally be built using the known
incomplete pulmonary implementation?

Reason for pushback: the current implementation:

- combines invasive mechanical ventilation and NIV support values;
- treats P/F ratio `<200` as an independent pulmonary start;
- does not implement the high-flow plus P/F `<300` tier;
- does not implement the non-rebreather tier;
- treats P/F ratio `>200` as a termination although this is not listed among
  the authoritative pulmonary termination events.

Building Sepsis 2 before deciding this would knowingly affect which encounters
meet organ dysfunction.

## Pulmonary tier interpretation question — awaiting owner answer

The document places a support modality and a P/F threshold under Tiers 1–3,
but it does not state whether those are independent alternative starts (OR) or
must occur together (AND). The `AND` visible in the support lines connects the
event grouper to its allowed value, not clearly the support event to the P/F
threshold. Before changing pulmonary logic, confirm whether the intended rule
is:

- Tier 1: invasive-ventilation evidence OR P/F `<100`; Tier 2: NIV evidence OR
  P/F `<200`; Tier 3: high-flow evidence OR P/F `<300`; Tier 4: non-rebreather
  evidence; or
- support modality AND the tier's P/F threshold for Tiers 1–3.

The authoritative end-event list contains nasal cannula/simple face mask/room
air, Vent Off Documentation, and Vent On/Off Standby or null. It does not list
P/F recovery as a termination event.

## Owner clarification and legacy verification

Owner decision:

- Only Tiers 1 and 2 establish pulmonary dysfunction.
- Pulmonary dysfunction starts with P/F ratio `<200`, invasive mechanical
  ventilation, or non-invasive mechanical ventilation.
- Tiers 3 and 4 are termination events.
- P/F ratio `>200` is also a termination event.

Boundary implication from the stated strict inequalities: P/F exactly `200`
is neither a start nor a termination and therefore does not itself change the
current pulmonary state.

Legacy verification found that the decision is only partially represented in
`src/configs/pulmonarydysfunction.py`:

- It does configure P/F `<200` as a start and P/F `>200` as termination.
- It configures invasive values (`ventilator`, `mechanical ventilator`) and NIV
  values (`CPAP`, `NPPV/NIV`) as starts, but omits `BiPAP`.
- It does **not** configure Tier 3 high-flow or Tier 4 non-rebreather events as
  termination events. Its oxygen-delivery termination list contains only nasal
  cannula, room air, and simple face mask.

No implementation changes were authorized by this clarification alone.

## Pulmonary termination correction implemented

The owner explicitly authorized correcting pulmonary dysfunction before
Sepsis 2 composition.

Changes:

- Added the documented Tier 3 high-flow grouper and five allowed values to the
  strategy configuration.
- Added the documented Tier 4 non-rebreather grouper and three allowed values
  to the strategy configuration.
- Extended the O2-delivery termination criterion so Tier 3/4 terminate only
  when both the configured grouper and an allowed value match. An unrelated
  value under either grouper does not terminate state.
- Included both groupers when selecting raw events for pulmonary transition
  reconstruction.
- Preserved all existing start rules, P/F `<200` start, P/F `>200`
  termination, P/F `==200` no-change behavior, other termination events,
  exclusions, and the termination-wins tie rule.

Validation:

- Focused correction suite: 21 passed.
- Full pulmonary/PF/organ regression selection: 46 passed.
- Full maintained test suite: 194 passed and 2 known stale expectation
  failures (SIRS enabled-state expectation and earliest-only infection-pair
  expectation). No new pulmonary failure occurred.
- Read-only source-data check found qualifying Tier 3 events in 2,943
  encounters and qualifying Tier 4 events in 1,663 encounters. Only aggregate
  counts were printed; no patient-level records were written or displayed.

Sepsis 2 composition has not yet been implemented; this correction is a
reviewable prerequisite increment.

## Timestamp-definition conflict — awaiting owner clarification

The owner subsequently proposed:

- `sepsis_2_dt = min(infect_dt, organ_episode_start)`
- `sepsis_1_dt = min(infect_dt, sirs_positive_episode_start)`

This conflicts with the earlier explicitly approved Sepsis 1 decision that
`sepsis_1_dt` is the later timestamp when both evidence components have been
established, with the minimum retained separately as
`sepsis_1_earliest_evidence_dt`.

Clarification requested: is the owner intentionally redefining `sepsis_1_dt`
and `sepsis_2_dt` as the first supporting-evidence timestamp, or should the
classification timestamps remain the later timestamp while the minimum stays
in separate `*_earliest_evidence_dt` fields? No code should change until this
semantic distinction is confirmed because it will directly affect POA/NPOA
classification.

Owner clarification:

- Keep the previously approved Sepsis 1 semantics:
  `sepsis_1_dt = max(infect_dt, sirs_positive_episode_start)` and retain the
  minimum separately.
- Apply the same semantics to Sepsis 2:
  `sepsis_2_dt = max(infect_dt, organ_episode_start)`.
- Add `sepsis_2_earliest_evidence_dt = min(infect_dt,
  organ_episode_start)`.

## Sepsis 2 implementation

The owner approved making Sepsis 2 parallel to Sepsis 1 after the timestamp
clarification.

Implemented:

- Added an organ-dysfunction episode adapter that reconstructs exact change
  points from source measurements, each feature's configured validity
  expiration, and pulmonary state transitions.
- The adapter re-evaluates the configured organ strategies at those change
  points, creates half-open state segments, collapses contiguous binary state
  into episodes, and retains the contributing organ flags and maximum
  simultaneous organ-dysfunction count.
- Missing organ evidence maps to state `0`, consistent with the project's
  approved missing/insufficient-evidence behavior.
- Added Sepsis 2 association logic using every exact-deduplicated infection
  anchor and the configured 48-hour backward/forward windows.
- A positive organ episode qualifies when its half-open interval overlaps the
  infection window. Exact zero-duration boundary contact does not qualify.
- For every qualifying association:
  - `sepsis_2_dt = max(infect_dt, organ_episode_start)`;
  - `sepsis_2_earliest_evidence_dt = min(infect_dt,
    organ_episode_start)`.
- Added an encounter summary that preserves negative encounters and reports
  association, distinct-anchor, and distinct-organ-episode counts.
- Sepsis 2 does not consume or require SIRS/Sepsis 1.
- Integrated exact organ segments/episodes, Sepsis 2 associations, and Sepsis
  2 encounter summaries into `main_strategy.py` with versioned no-overwrite
  output names.

Validation:

- Organ episode adapter plus Sepsis 2 focused tests: 8 passed.
- Organ/Sepsis focused regression selection: 40 passed.
- Full maintained suite: 202 passed with the same 2 known stale expectation
  failures (SIRS enabled-state and earliest-only infection-pair expectations).
- Read-only real-data smoke test:
  - 2,862,097 exact organ state segments;
  - 129,842 organ episodes, of which 57,897 are positive;
  - 309,240 deduplicated infection anchors;
  - 442,316 qualifying Sepsis 2 evidence associations;
  - 10,594 Sepsis 2-positive encounters among 14,914 encounters.
  No patient-level records were displayed or written.
